# Weather Dashboard 🌦️

A Flask-based Weather Dashboard web application that fetches real-time weather and 5-day forecast data using the OpenWeatherMap API.

## Features 

- Search weather by city name
- Real-time temperature display
- Weather description
- Feels like temperature
- Humidity information
- Wind speed details
- 5-day weather forecast
- Dynamic weather icons

## Technologies Used 🛠️

- Python
- Flask
- HTML5
- CSS3
- OpenWeatherMap API
- Requests Library
